# 📊 Global Sales Analytics Dashboard | Power BI Project

## 📌 Project Overview
An interactive **Power BI Sales Performance Dashboard** built to analyze sales volume, revenue, and profit margins across key global markets.

## 🎯 Key Features
* **Geographic Map Visual:** Interactive spatial analysis tracking regional sales hotspots (India, USA, UK, Germany, China, Japan).
* **Executive KPIs:** Dynamic metrics displaying Total Sales, Total Profit, and Units Sold.
* **Product & Category Analysis:** Visual breakdowns of Top 5 Products and Category Market Share using Bar and Donut charts.
* **Interactive Slicers:** Country-level dynamic filters for real-time analysis.

## 🛠️ Tech Stack
* **BI Tool:** Power BI Desktop
* **Data Processing:** Power Query & DAX (`SUM`, `Total Sales`, `Total Profit`)
* **Data Source:** Excel Dataset (`.xlsx`)
