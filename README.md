# 📊 Global Sales Analytics Dashboard | Power BI

## 📌 Overview

An interactive Power BI dashboard designed to analyze global sales performance, revenue, profit margins, and sales volume across different regions and markets.

The dashboard transforms sales data into meaningful business insights using interactive visualizations, KPIs, filters, and geographic analysis.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Track revenue and profit margins
- Compare regional sales performance
- Identify high-performing markets
- Understand sales volume trends
- Present business insights through interactive dashboards

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Transformation
- Data Visualization
- Interactive Dashboard Design

## 📈 Key Features

- 📊 Sales & Revenue KPIs

- 🌍 Regional Sales Analysis
- 🗺️ Geographic Sales Visualization
